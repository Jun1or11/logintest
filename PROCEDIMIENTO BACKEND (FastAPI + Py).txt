✅ RESUMEN: Conexión Frontend ↔ Backend ↔ Base de Datos
🔹 FRONTEND (Vercel / React + Vite)

El frontend NO debe tener la URL del backend escrita en el código.

Usa una Environment Variable.

En Vercel → Settings → Environment Variables:

VITE_API_URL = https://logintest-oqud.onrender.com

En el código (api.ts):

const API_URL = import.meta.env.VITE_API_URL;

👉 Esta variable conecta el frontend con el backend.

🔹 BACKEND (Render / FastAPI)

El backend NO debe tener datos de la BD en el código.

Usa una Environment Variable.

En Render → Environment Variables:

DATABASE_URL = postgresql://usuario:password@host:puerto/dbname

En el código (main.py):

DATABASE_URL = os.getenv("DATABASE_URL")
psycopg2.connect(DATABASE_URL)

👉 Esta variable conecta el backend con PostgreSQL.

🔹 CORS (Backend – obligatorio)
allow_origins=[

🔗 DEPENDENCIAS CLARAS

Frontend 👉 depende de VITE_API_URL

Backend 👉 depende de DATABASE_URL
